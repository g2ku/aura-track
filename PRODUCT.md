## Platform

web

## Users

- **Владелец сети кофеен** — ежедневно, несколько раз в день, в основном с телефона (мобильный web — главный сценарий; десктоп — вторичный). Работает на ходу: между точками, утром и вечером.
- **Менеджеры филиалов** — заносят/сверяют данные по своей точке, чаще с телефона. (подтверждено владельцем: «Телефон — главный»)

Confirmed in interview: phone-first, касса + быстрый доступ к «то сё» — главная работа, текущий интерфейс «всё не так».

## Product Purpose

Aura Track — операционный пульт сети кофеен: контроль касс по точкам, финансовая отчётность (отчёты, ПНЛ, оплаты, долги), склад и поставки через Poster. Продукт делает видимым состояние каждой точки за несколько секунд: сошлась ли касса, сколько денег в обороте, что требует внимания.

## Positioning

Операционная сводка сети в один взгляд для владельца: не бухгалтерская система и не CRM, а «пульт заведения» — касса, остатки, долги и отчёты на одном экране, без лишних кликов.

## Operating Context

- Ежедневный ритуал владельца: быстро узнать кассу точки → увидеть, что срочно → уйти по делам. Сессии короткие (15–60 секунд), часто одной рукой, на ходу.
- Отчёты загружаются из Excel (листы филиалов), Poster — кассы/поставки/меню.
- Роли: admin (видит всё, загружает отчёты), manager (то же без части админки), curator (только своя точка), user.

## Capabilities and Constraints

- Подтверждённые функции (сохраняются при редизайне): дашборд по точкам, отчёты с листами филиалов, оплаты/долги, ПНЛ, маржа, склад/остатки, Poster-интеграция (кассы, поставки, меню), инвентаризация, команды через ИИ-чат, экспорт.
- Авторизация: Firebase (email/password), метаданные ролей в Firestore.
- Техстек: React + Vite + zustand, CSS-переменные (темы), Chart.js. Мобильный web, без нативных рамок. Одна рука, крупные цели от 44px.
- Стейт-баг, который нельзя повторить: `data-theme` применялся только по клику, сохранённая тема игнорировалась при загрузке (уже исправлено).

## Brand Commitments

- Название: Aura Track. Кофейный контекст сети — точки «Aura». Тёплые кофейные тона/эспрессо-палитра подходят бренду, но не обязательны к сохранению (редesign — полная свобода, подтверждено).
- Язык интерфейса: русский.

## Evidence on Hand

- Реальные данные: отчёты сети, Poster-кассы, долги, оплаты (прод).
- Дизайн-претензия владельца: «текущий интерфейс — всё не так», «не перегружать экран, пользователь не должен теряться», «максимально удобно, особенно мобилка».

## Product Principles

1. Мобильный первый: главный экран — «касса в один взгляд», сессии 15–60 сек одной рукой.
2. Минимум кликов: любое «то сё» — в 1–2 нажатия от дома.
3. Один взгляд — одно решение: экран не перегружен, иерархия видна мгновенно, пользователь не теряется.
4. Операция не маскируется красотой: кассу и статусы видно сразу, детали — по запросу.

## Accessibility & Inclusion

- Мобильная эргономика: тёпловые зоны, крупные цели (≥44px), контраст текста ≥4.5:1, поддержка reduced-motion.
