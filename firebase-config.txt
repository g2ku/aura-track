(Project settings → Your apps → </> )

                → ⚙️ Project settings
                → секция "Your apps"
                → иконка </>
                → если нет web-приложения — нажми и зарегистрируй
                → скопируй значения ниже из кода firebaseConfig

─── Как выглядит в Firebase Console ─────────────────────────

Вот так выглядит код firebaseConfig в Firebase Console после регистрации web-приложения:

  const firebaseConfig = {
    apiKey: "AIzaSyAbc123XyZ...",                  ← сюда
    authDomain: "my-project.firebaseapp.com",      ← сюда
    projectId: "my-project",                       ← сюда
    storageBucket: "my-project.appspot.com",       ← сюда
    messagingSenderId: "123456789012",             ← сюда
    appId: "1:123456789012:web:abc123def456"        ← сюда
  };

Все 6 значений нужны — без любого приложение не запустится.

─── Правила Firestore ───────────────────────────────────────

Также нужно опубликовать правила. Зайди в:
  Firebase Console → Build → Firestore Database → вкладка "Rules"

Замени всё на:
  rules_version = '2';
  service cloud.firestore {
    match /databases/{database}/documents {
      match /{document=**} {
        allow read, write: if true;
      }
    }
  }

Нажми "Publish".

─── После заполнения ────────────────────────────────────────

1. Заполни все 6 значений выше (вместо пустых строк)
2. Сохрани файл
3. Скинь мне содержимое этого файла
