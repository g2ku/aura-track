# Design System — Aura Track

Мир: **«Термолента»** (thermal receipt strip). Направление назначено роллом
`concept-seed` (seed `4b60e369`), выбрано владельцем. Контракт направления —
комментарий в `index.html` (первый ребёнок `<body>`).

## Тезис

Сеть кофеен читается как стопка термолент: касса, долги и статусы видны
строчками чека — без карточек-метрик, дашбордных героев и градиентов.
Главный экран отвечает на вопрос «что с кассами и что срочно?» за 3 секунды,
любое «то-сё» — в 1–2 нажатия.

## Мир и материалы

- **Поверхность** — бумага: светлая тема «бумага» (#f4f1ea), тёмная «ночная
  смена» (#16130e). Никаких карточек-коробок: разделение — **пунктирными
  правилами** и **точечными лидерами** (`label ······ value`), жирный ИТОГО.
- **Чернила** — `--text` на светлой (почти чёрное), бумажный `--text-invert`
  на тёмной. Кнопки-«оттиски»: главная — заливка чернилами, вторичная —
  контурная, призрачная — без обводки.
- **Синька** (копировальный слой) — единственный хроматический акцент
  `--text-accent` (синий): ссылки, активные пометки, фокус. Статусы —
  функциональные чернила (success/warning/danger) без украшательства.
- **Штампы** — статусные плашки: caps-микротипографика с разрядкой, вид
  «печати» (единственное авторское движение — `stampIn` 0.22s).
- **Глубина** — только границы. Тени допустимы у модалок/тостов/шед.
- **Цифры** — моноширинный стек + tabular-nums везде, где деньги и счётчики.

## Типографика

- Одна семья: Inter (системный стек). Моно-стек для сумм и ID.
- Колпачковые микро-заголовки: 10–11px, weight 700–800, tracking 0.08–0.16em,
  uppercase — для зон и заголовков секций (язык кассовых лент).
- Суммы: 19–26px, weight 700, letter-spacing −0.02em, tabular.
- Заголовки страниц: 22–26px, weight 800, tracking −0.02/−0.025em.

## Компоненты

- `Stamp` — статус (ok/warn/bad/accent), caps + иконка + штамп-анимация.
- `cl-line` — строка чека: label + dotted leader + value (mono).
- `cl-spot` — точка: название + штамп + касса + строки-лидеры.
- `cl-chip` — мини-блок «то-сё»: пунктирная рамка, caps-подпись, хинт-цифра.
- Кнопки: `.btn-pri` (чернила) / `.btn-out` (контур) / `.btn-ghost` / danger /
  success; min-height 40px (44px на мобильных), радиус 8px.
- Поля: hairline-бланк, фокус — пунктирное кольцо `--text-accent`.
- Таблицы «ведомости»: caps-шапки, hairline-строки, ИТОГО жирным.
- Табы: сегментированная рамка, активная вкладка — чернильная заливка.
- Модалки: лист поверх бумаги, dashed-разделители шапки/подвала.
- Нижняя навигация — «подвал чека»: пунктирные вертикальные разрезы,
  активный пункт с 2px маркером сверху.
- Боковая панель: прозрачная, hairline-грань; активный пункт —
  жирный с подчёркиванием-линией.

## Состояния и детали

- Выполнено-отметка («проверено») — зачёркивание + штамп ok (рукописная
  пометка в каталоге; из мира doujin catalog) + persistence в localStorage.
- Скелетоны на загрузку Poster, тосты-«обрывки» с сылкой для закрытия.
- Фокус-кольцо — 2px dashed синька; selection/caret/scrollbar выведены в
  палитру. reduced-motion выключает движение.

## Адаптив

- Мобильный первый: контент 16px по краям, 84px под нижнюю навигацию.
- Десктоп: лента и ведомости шире (max 1280px), sidebar слева.
- Точки перелома и плотности наследуются от базовой CSS-системы.

## Дисциплины, поднявшие мир (raises)

1. **Doujin catalog** — пометка «проверено» зачёркиванием для долгов.
2. **Saville catalog** — «одна надпись на вещь»: без дублирующих подписей.
3. **Oscilloscope bench** — «все сигналы одной строчкой»: статус точки
   сжат в одну строку-лидер.
