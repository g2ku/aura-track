# Лабораторная работа №2 — «Кладовщик»

Архитектура, UML-диаграммы, документация и GitHub проекта «Кладовщик» —
системы операционного учёта для сетей общепита.

Команда: Кулуш Асхат, Камалова София, Ермухан Равиль, Жолдыгалиев Серик.

| Файл | Что это |
|---|---|
| `Кладовщик — ЛР2.docx` | отчёт в Word: тема, инструменты, UML, документация, GitHub |
| `kladovshchik.html` | презентация (16 слайдов, открыть в браузере; ← → листать, N — заметки) |
| `uml/*.svg`, `uml/*.png` | восемь диаграмм: архитектура, варианты использования, 4 последовательности, деятельность, путь коммита |
| `gen_uml.py` | генератор SVG-диаграмм |
| `render.sh` | SVG → PNG через headless Chrome |
| `build_deck.py` | сборка презентации со вставленными SVG |
| `build_docx.cjs` | сборка отчёта Word (нужен пакет `docx`) |

Пересобрать всё:

```bash
python3 gen_uml.py && ./render.sh
python3 build_deck.py
npm install --no-save docx@9 && node build_docx.cjs   # --no-save: не трогать package.json проекта
```
